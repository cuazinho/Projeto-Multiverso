# **App Name**: Multiverse Explorer

## Core Features:

- Profile Creation: Users can create a profile with their name, identification name, purpose, universe name, and profile image.
- Profile Image Upload: Allow users to upload a profile picture to personalize their profile.
- Profile Listing: Display a list of all registered users with their names.

## Style Guidelines:

- Primary color: Deep indigo (#4B0082) to represent the vastness of the multiverse.
- Background color: Light gray (#E0E0E0) to provide a neutral backdrop that highlights content.
- Accent color: Electric violet (#8F00FF) to draw attention to key interactive elements.
- Headline font: 'Space Grotesk' sans-serif for a modern and slightly techy feel.
- Body font: 'Inter' sans-serif for a clean and readable design.
- Use minimalist icons to represent profile settings and other options.
- Subtle transitions between pages and interactive elements to improve UX.
